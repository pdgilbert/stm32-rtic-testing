//! displayX2_rtic* programs attempt to use two ssd1306 displays on shared i2c buses.
//! Version displayX2_rtic0   constructs display_a and display_b on i2c buses with
//! AtomicCell and AtomicDevice in init, but does not share them and only displays in init.
//! This is pretty useless, but demonstrates AtomicCell and AtomicDevice display init syntax.

//  4b put displays on separate I2c buses, so does not needs I2c bus sharing.
//  4a1 put displays on the same RefCell(I2c)  bus  with access from a single thead.
//  4a2 put displays on the same I2c buses with access from two theads.

//! Version displayX2_rtic1 constructs the shared i2c buses in rtic Local {}
//! Spawns tasks to construct display_a and display_b.
//! This does not share the i2c bus, share the resources, or share displays,
//! but it does put i2c resources in Local, so they have a 'static lifetime.

//! Version displayX2_rtic2 attempts to constructs display_a and display_b
//! and put them in Local {}. It does *not* build.
//! This does not share the i2c bus, share the resources, or share displays.

//! Version displayX2_rtic3 attempts to constructs display_a and display_b
//! and put them in Local {} using MaybeUninit.
//! This does not share the i2c bus, share the resources, or share displays.

//! See 
//!  https://github.com/rtic-rs/rtic/blob/master/examples/rp2040_local_i2c_init/src/main.rs
//!  https://docs.rs/embedded-hal-bus/latest/embedded_hal_bus/i2c/index.html
//!  https://docs.rs/embedded-hal-bus/latest/embedded_hal_bus/i2c/struct.RefCellDevice.html

// https://docs.rs/embedded-hal-bus/latest/embedded_hal_bus/i2c/struct.RefCellDevice.html
// RefCellDevice instances are not Send, so it only allows sharing within a single thread (interrupt priority level).
// If you need to share a bus across several threads, use CriticalSectionDevice instead.

//    - various lifetime 'a problems and complication because
//         init signature`#[init]` function must have signature `fn(init::Context) -> (Shared resources struct, Local resources struct)`
//    - putting dispay in Share  adds extra `&mut and fails at 
//              let display_b:DisplayBType = cx.local.display_b;
//    - putting interface in Share  adds extra `&mut and fails at 
//            let interfaceB:Interface2Type = cx.local.interfaceB
